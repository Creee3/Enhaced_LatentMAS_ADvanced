## 2. 研究路线怎样演变

1. 原始问题：LatentMAS多角色交接时，怎样在更少KV字节下保留有用信息？原LatentMAS是系统基础，Full是完整KV参照。
2. 几何分解路线：作者HeadOBF与题内JIVE。它们提供已有方法参照或项目改编对照，不等于我们的新理论。
3. 接收方感知路线：旧receiver通过下一角色prompt query给位置打分，直接保留原KV，不拟合V。这成为后续改进的基础。
4. 曾讨论的修补路线：receiver+OBF、核范数谱收缩、接收方输出拟合、独立query验证后再决定是否修补。相关原型/问题卡存在，但本轮未运行这些候选的模型效果实验。
5. 用户澄清导师意图：从各角色贡献与差异入手，而不是把其他学生的联邦学习任务混入本研究。
6. 当前路线：T保持总读出、R保持来源块读出、R-shuffle用假边界检验真实角色结构。先两题三次工程试跑，再启动main448，最终按用户要求暂停于225道完整共同题。

导师方向的用户确认版本是“从每个角色的信息方向/差异入手，再汇总”。当前R只是对该方向的一个窄实现：保持来源分块的读出。它没有完成语义方向分解，也没有抽取已证明有用的独有知识。

## 4. 当前三个方法究竟是什么

对固定的一层、一个KV头，把对应4个GQA query头的最后16个prompt query堆成64个观测。令完整当前可用缓存上的注意力为a(q,j)，Value为v_j；S同时包含交接保留行和用于目标计算的固定接收方self行。

    z_S(q) = sum_{j in S} a(q,j)
    Y_S(q) = sum_{j in S} a(q,j) v_j / z_S(q)
    C_{b,S}(q) = sum_{j in S intersect block_b} a(q,j) v_j / z_S(q)

T最小化总读出均方误差mean((Y_full-Y_S)^2)。R最小化四块读出均方误差mean_b mean((C_b,full-C_b,S)^2)，块0为self/sink，其余三块为生产角色来源。R-shuffle只更换来源分组，保持数量并错移连续边界；self/sink组不变。它不是简单交换角色名字。

三臂从相同attention候选bank开始，以后向贪心删除降低各自目标，最终原KV直接gather、原RoPE，无Value拟合或回填，无SVD/JIVE/核范数。该局部teacher是前两次receiver压缩后的当前可用缓存，不是官方Full整条轨迹。贪心解不保证全局最优。

前两次交接冻结旧receiver；只在第三次交接改变选位。最多192候选prompt选96，Refiner末8prompt必留，全部30latent和4sink受保护，共130行。36层×8KV头，每层每头可以选不同原位置，但长度相同。

旧receiver每次当前角色32prompt配额并保留既往已选历史；新末次选择允许对仍可用prompt共同重选。因此T对旧receiver的差别同时涉及候选/配额/历史重选和目标函数。没有运行单独的G全局attention控制臂，不能把提升完全归因于读出匹配。T/R/shuffle之间的对比则共享这些条件。

当前R不是最初lambda=1的“整体+中心化差异”原型；正式使用显式四块匹配。也没有新增独立未来latent query的留出评估，不能宣称已证明未来query泛化。

## 5. 本轮KV压缩口径

225题上所有六种压缩方法最终交接预算相同，每题19,169,280字节，约18.28MiB；Full同题平均约143,226,962字节。

| 范围 | 保留比 | 减少比 |
|---|---:|---:|
| 共同225题 | 13.38% | 86.62% |
| Diamond106 | 13.34% | 86.66% |
| 非Diamond119 | 13.42% | 86.58% |

比值=各题压缩KV总字节/相同各题Full总字节，减少比=1-保留比。Full可按实际位置×锁定BF16维度147456字节/位置推算。此为Judger前最终交接缓存，不是整个推理峰值、所有交接累积通信量或FLOP节省。新方法实测保留张量字节通过核对。

## 6. 讨论过的方法清单及证据状态

| 思路 | 解决什么 | 当前状态与归属边界 |
|---|---|---|
| 原LatentMAS/Full | 潜在思考与角色状态交接 | 上游系统基础、完整KV参照；非我们的创新 |
| 作者HeadOBF | 选位后对删除V的正交残差提取低秩方向并回填 | 上一轮已跑；来自《When Less Latent Leads to Better Relay》相关作者实现，项目冻结rank8，不冒充其所有默认配置 |
| 题内JIVE | 同题多视图共同/特有线性结构 | 上一轮已跑，共同4/特有4、固定20轮近似；不是完整AJIVE，也不是语义知识分解证明 |
| receiver注意力选位 | 根据下一角色实际query决定留下哪些行 | 上一轮已跑；已有receiver-aware先例，不能把整个概念宣称首创 |
| receiver+OBF | 先receiver选位，再做已有OBF修补 | 隔离原型与机械测试，未进入本轮真实答案生成；是已有算子组合控制，不是充分创新点 |
| 核范数/谱软阈值 | 收缩残差方向强度，控制低秩修补 | 独立原型/消融思路，未跑效果；截断谱收缩不等于完整核范数近端求解 |
| 精确Gram特征分解 | 用R^T R求右奇异子空间 | 数值求解路径，不是新的压缩目标；未证明更快 |
| 随机SVD/子空间迭代/Frequent Directions | 近似或流式估计子空间 | 随机原型在合成压力测试有修正量偏差；不能当精确替换，也不等于真实KV失败证据；非本轮方法 |
| Attention Matching式输出拟合 | 直接拟合query看到的输出，相关先例也考虑注意力质量 | 已有理论来源；本轮T借鉴输出保持目标但只选原行，没有复现完整Value/偏置拟合 |
| 可拒绝的接收方Value修补 | 拟合后由另一组query决定混合强度alpha，必要时拒绝 | 研究问题卡，未做真实模型效果实验；局部误差不增加不保证最终答案改善 |
| 率失真/AATC启发 | 总字节预算怎样分配到重要分量 | 历史文献讨论，未实现动态行预算；量化比特分配不能直接等同删KV行 |
| Error feedback | 保存压缩残差、下轮补偿 | 思想参考；单次接力与梯度反复更新不同，额外残差需算预算；未跑 |
| G全局attention控制 | 区分历史共同重选与输出目标的收益 | 最初设计提到，正式三臂没有运行 |
| T/R/R-shuffle | 总读出保持、来源块保持与假边界负控制 | 本轮真实运行，暂停于共同225题；主要新证据来源 |
| 直接选择latent/按层头动态预算 | 更直接触及角色推理贡献与预算配置 | 后续候选，未实施，也未授权恢复或启动 |

联邦学习冲突层选择来自用户转述中其他学生的工作，不是本实验训练任务、已实现模块或已验证理论来源。保留“关注角色差异”的本研究动机，不能把联邦训练的机制/结论搬成本项目贡献。

## 7. 哪些话需要纠正或收窄

- “OBF正交残差回填是我们的创新”：不成立，它是已有方法。之前列入候选只表示可组合验证，容易造成创新归属误解，应明确纠正。
- “SVD慢，所以应排除SVD”：不成立。应先选对目标，再比较求解器；有无SVD本身不是创新。
- “共同/特有分量就是共同/独有知识”：不成立，只是特定表示与坐标下的线性结构。
- “lambda=1一定弱27倍”：初始评论涉及不同归一化，不能据此断言实际影响微弱；self行不删也会因softmax重归一化而改变读出。正式方案已改为显式四块目标。
- “latent都保护，所以角色latent读出完全不变”：不成立，prompt删除会改变归一化权重和后续query。但本轮确实没有选择性删除latent，仍不能声称提取了角色推理差异。
- “T与Full同样强”：非Diamond上只是64题正确数相同；全部225题T少2题。没有等效性检验和跨设置证据。
- “R已经证明导师方向有效”：当前证据不足，尤其非Diamond与shuffle同分，整体低于T；Diamond优势也只有3题净差。
- “压缩86.62%就是省同样显存/时间/通信”：不成立，本指标仅最终交接KV字节。
